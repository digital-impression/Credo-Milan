# Beeldcatalogus — bronmateriaal Credo

Overzicht van de 197 foto's in de branch `media-source`, doorgenomen op
leesbaar formaat. De nummers verwijzen naar de volgorde waarin de bestanden
gesorteerd staan (`assets/Nieuwe map (2)` eerst, dan `assets/Nieuwe map`,
alfabetisch). Gebruik dit om te kiezen; niet meer op miniaturen af gaan.

## Waarom dit bestand bestaat

De eerste keuzes op de site waren middelmatig omdat ik de foto's beoordeelde
op contactvellen van 230 pixels. Op dat formaat zie je compositie noch
scherpte noch of iemand zijn ogen dicht heeft. Deze catalogus is één keer
gemaakt op 440 pixels per beeld, zodat elke volgende keuze uit een index komt.

## Wat er niet in zit

- Geen enkele patiënt boven de dertig. Alle modellen zijn atleten in clubkledij.
- Geen behandeling met de handen op een lichaam, behalve 034 en 036.
- Geen dry needling, geen naalden.
- Geen wachtzaal, geen onthaal, geen administratie.
- Eén enkel jeugdbeeld (094).
- Het ijsbad staat alleen op de foto's die van de oude site komen, niet in deze set.

Wie een fotograaf terugstuurt: dit lijstje is de opdracht.
